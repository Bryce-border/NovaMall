# 券券宝与商城交互

## 启动与初始化

已有数据库先备份并执行 `database/init/010-coupons-reviews.sql`。该迁移仅新增五张表，重复执行不会重置数据。构建并重启 `mall-order` 和 `mall-gateway` 后，在项目根目录执行：

```powershell
node scripts/seed-coupon-demo.mjs
```

脚本按活动名称去重，默认通过 `http://127.0.0.1:18080` 创建三种活动：免费满 20 减 5、19.9 元购买五张满 20 减 5、下一整点开放的限量券。默认活动开放七天，券有效期三十天。重复执行不重置已发份数和用户券，也不会延长旧活动；过期后可在管理端创建新活动。

`NOVAMALL_GATEWAY`、`NOVAMALL_ADMIN_USERNAME`、`NOVAMALL_ADMIN_PASSWORD` 可覆盖脚本配置。购买券包和商品支付均为模拟支付，券包发放要求 `MOCK_PAYMENT_ENABLED=true`。

## 页面入口

- `#catalog`：顶部分类菜单、准确的手机数码分类入口、滚动加载商品和返回顶部。
- `#product?id=…`：显示当前规格已加入数量，可直接增减；确认收货后评论，每个账号每商品一条；最多推荐四件同分类在售商品。
- 页面左下购物车：商品图、数量调整、选择商品、选券与预估金额；去结算跳转 `#checkout`，确认地址提交后进入 `#payment?no=…` 收银台。
- `#coupons`：券券宝，显示数量、开放/截止时间、到期时间及倒计时。
- `#wallet`：已拥有、已过期、已使用三个栏目。锁定中的券可查看关联订单。
- `#admin`：商品表格铺满主内容区；新增商品、分类、编辑、补库均使用原生 dialog 弹窗。
- `#admin?view=coupons`：发布活动，填写数量、时间、满减金额、券包价格和张数；已发布活动可暂停或恢复发放。

窄屏导航自动换行，分类下拉展开成两列；购物车浮窗收窄到屏幕宽度以内。管理弹窗限制高度并可滚动，表格保留横向滚动。

## 规则与事务

活动按“份”计数。免费券每份一张、价格零；券包每份 1–20 张。每账号每活动最多领取/购买一份，限额覆盖请求重试。券全场通用，满减金额均以元计，每单一张、不叠加。

`mall_coupon_campaign` 的行锁串行处理同一活动的领取，并在同一事务更新已发份数、写入领取/模拟支付记录及用户券。`(campaign_id,user_id)` 唯一键避免重复领取；成功请求重试返回原来的券，不再收费或发券。券包价格由后台活动读取，客户端只确认模拟支付。

购物车结算请求增加可选 `couponId`，并在 `mall_checkout_coupon` 中绑定原请求键。复用请求键时更换券会被拒绝；省略字段兼容原无券调用。服务端在订单创建事务内检查券归属、状态、有效期和商品金额门槛，将券锁定到订单，记录订单优惠及最终应付金额；结算失败事务回滚并释放远程库存预占。价格和优惠不会采信客户端计算结果。

模拟支付与券核销在同一事务完成。取消订单、订单支付超时与退券在同一事务完成；过期后退回的券在钱包中显示已过期。锁定后在订单支付期限内可付款，即便此间券到期。活动暂停只停止新领取，已发出的券按领取时快照使用。

订单详情和支付记录显示抵扣后的实际模拟付款金额。券包购买在确认框确认后立即模拟支付并发券，支付金额记录在 `mall_coupon_claim`；当前没有券包退款、转赠、多券叠加或按商品/分类限定使用功能。

## API

| 方法与路径 | 用途 |
|---|---|
| `GET /api/coupons/campaigns` | 公开活动列表，带服务端时间 |
| `POST /api/coupons/campaigns/{id}/claim` | 当前账号领取；券包需 `{ "confirmMockPayment": true }` |
| `GET /api/coupons/mine` | 当前账号的券和使用状态 |
| `GET /api/coupons/admin` | 管理员活动列表 |
| `POST /api/coupons/admin` | 管理员创建活动 |
| `PUT /api/coupons/admin/{id}/status?status=0或1` | 暂停或恢复发放 |
| `GET /api/reviews/{productId}` | 最近 50 条商品评价，买家名称脱敏 |
| `POST /api/reviews/{productId}` | 已购并确认收货的买家评价，`rating` 为 1–5，`content` 最长 1000 字 |

活动创建字段：`name`、`kind`（`FREE` / `PACK`）、`thresholdAmount`、`discountAmount`、`packPrice`、`packSize`、`totalQuantity`、`opensAt`、`closesAt`、`expiresAt`。时间使用北京时间的 `yyyy-MM-ddTHH:mm:ss`。减免金额不超过门槛，开放早于截止，到期不早于截止。

2026-10-10：22 项订单/购物车单元测试通过；DOM 交互检查覆盖导航分类、滚动加载、数量提示、推荐与评论、悬浮购物车、结算页面及四种管理弹窗。浏览器自动化初始化失败，未完成实际浏览器视觉检查。

本地接口验证：

```powershell
node scripts/coupon-check.mjs
```

脚本需本机网关、Docker MySQL、模拟支付/履约开关及数据库迁移就绪。它创建独立测试账号、商品与活动，完成 13 项检查：管理权限、未开放拒绝、最后一份并发领取、五张券包与重试幂等、评价购买资格、券归属、门槛、过期状态、结算抵扣/锁定/重试、取消释放、支付核销、评价去重、超时释放。等待超时调度器可能需要约一分钟。结束后移除测试活动并软删除测试商品，保留测试账号及其订单记录供排查；不会消耗现有 24 件展示商品的库存或改变其销量。
